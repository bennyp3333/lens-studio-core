# lens-studio-core

Personal Lens Studio (Snap) script library. Projects import the compiled `Core.lspkg`;
source lives here.

**Full API + code-style digest:** @CORE_AI_REFERENCE.md — read it before using Core APIs or
writing a new script. It lists every script, every `global.*` / `script.*` entry point, and
the house coding conventions, with absolute paths to each source file for deeper detail.

New scripts start from `Components/BaseScript.js` (see the reference, §3.1).
